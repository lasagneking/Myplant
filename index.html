How to use your key in the browser

  1. Create an account and generate an API key on my.plantnet.org
  2. In the API key settings, check “Expose my API key”
  3. Add your domain (or http://localhost:xxxx for local testing) under Authorized domains
  4. Paste the key above and click Save

Your key is stored only in your browser’s localStorage and never sent anywhere except to Pl@ntNet.
